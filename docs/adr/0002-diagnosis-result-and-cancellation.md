# ADR 0002 诊断结果与取消确认

日期为 2026-11-24。状态为已采纳。

用工单版本绑定诊断任务。结算时先锁工单，再用任务租约令牌条件更新。已有更新版本的工单保留新状态，迟到结果在任务中留存并写入审计。

Python 取消可登记占位记录，避免迟到的创建请求启动此前已取消的任务。已运行时先返回 CANCEL_REQUESTED，等待运行结果或有效租约结束后的恢复策略。Java 进入 UNKNOWN_OUTCOME 后需要人工核对。外部模型调用的响应丢失无法从 HTTP 判断计费或执行是否发生，Python 不自动重复该执行。

无遥测时，报告结论为 INSUFFICIENT_EVIDENCE，检查项是调查建议。Java 将仍处于相同版本的工单移交 MANUAL_REVIEW。
