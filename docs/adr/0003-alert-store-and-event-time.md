# ADR 0003 告警接收与事件时间

日期为 2026-11-24。状态为已采纳。

接收的原始请求、去重结果和分诊候选在 MySQL 同一事务内提交。使用来源与事件键识别可重放通知，使用单独的告警指纹描述被观测实体。一个批次可包含已存在的告警事件，回执仍保存每项处理结果。

同组事务串行推进事件时间水位。以可索引的淘汰区间扣减各严重级别的计数，允许窗口内乱序到达。冷却限制分诊候选生成频率，原始告警仍可追踪。

接入请求在数据库事务提交后执行 Redis Lua，缓存错误通过度量记录。候选判断读取持久化统计，避免引入数据库与缓存的分布式提交。当前投影不带历史重建作业，不能作为入口限流或计费依据。
